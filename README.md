# Descargas de LDT Tecnología

Instaladores oficiales de los programas publicados en https://ldt-tecnologia.blogspot.com/p/descargas.html

- **Receipt Creator 1.0**: crear, imprimir y guardar recibos con original y copia (Windows y macOS). Ver [Releases](https://github.com/joanrdr/ldt-descargas/releases).

La carpeta `capturas/` tiene las imágenes que se muestran en la página de descargas.
